# Skill: Book Discovery

## Trigger
用户要求寻找新书、执行每周书目发现，或当前候选池不足。

## Goal
发现跨学科、可核验、具有解释力且可能适合制作视频的书籍，不以畅销榜或社交热度作为唯一依据。

## Procedure
1. 阅读频道定位、历史书籍总库和视频项目台账。
2. 设定本轮主题组合，覆盖心理学/认知科学、社会学/人类学、哲学/思想史、经济学/行为经济学、历史/文明、科学/生命/演化、技术/组织/未来社会。
3. 搜集至少 20 个原始候选。尽量使用多个独立来源；优先出版社、作者/机构、图书馆目录、专业书评、学术评论、奖项与课程书单。
4. 对每个候选记录发现来源和书籍身份线索；不允许从单一社交帖子直接认定书籍信息。
5. 先粗筛明显不适配、信息无法核验、只有营销噱头或缺乏实质内容的候选。
6. 对其余候选写入 `01_book_discovery/candidates.md`，包含书名、作者、年份/版本线索、学科、来源链接、潜在中心问题、待核验事项。
7. 交给 book-selection 技能核验、评分和去重。

## Output
- 候选清单及来源
- 学科覆盖摘要
- 缺失信息与核验阻塞
- 本轮搜索范围及未覆盖范围

## Constraints
不得虚构书名、作者、奖项、销量或评分；不要声称已查遍所有书籍；不要把发现阶段的猜测写入总库为已核验事实。
