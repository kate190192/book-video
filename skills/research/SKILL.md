# Skill: Research and Evidence Ledger

Build a traceable evidence base before drafting. Separate:
- book author's own claims;
- findings from primary research;
- expert interpretation/review;
- broader consensus;
- disputed claims;
- the creator's synthesis.

For each important claim, record: claim ID, exact claim, source title, author/organization, source type, URL/DOI/ISBN when available, publication date, access date, what the source supports, limitations, confidence, and script sections that rely on it.

Prefer primary studies and authoritative institutional sources for empirical claims; use academic reviews and specialist criticism to understand context and disputes. A book review may establish a critic's view, not prove the underlying scientific claim.

Outputs:
- `04_research/evidence_ledger.md`
- `04_research/research_summary.md`

If sources disagree, summarize the disagreement and narrow the claim. Never fabricate quotations, page numbers, statistics, DOI, or source access. Mark unresolved claims and block script approval if they are central.
