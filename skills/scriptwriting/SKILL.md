# Skill: Scriptwriting

## Input
Approved topic brief, research summary, evidence ledger, channel config, desired duration.

## Workflow
1. State the central question and one-sentence answer privately before drafting.
2. Create a claim chain: problem → mechanism/explanation → evidence/example → counterargument/limit → synthesis.
3. Write the opening to establish a concrete tension, not generic greetings or exaggerated promises.
4. Develop 3–5 connected argument movements. Each movement should advance the answer; do not merely summarize chapters or list quotes.
5. Distinguish what the author argues from what evidence independently supports.
6. Close by answering the opening question, identifying the book's contribution and limits, and ending naturally.
7. Add production-friendly scene breaks without changing argument order.
8. Map factual claims to source IDs in `citation_map.md`.
9. Estimate duration using configured narration rate and flag passages likely to be visually repetitive.

## Outputs
- `05_script/script.md`
- `05_script/scene_plan.json`
- `05_script/citation_map.md`

## Style
Use natural spoken Chinese, clear transitions grounded in logic, varied sentence rhythm, and precise terminology. Avoid repetitive rhetorical templates, empty summaries, excessive short fragments, fake suspense, and repeated conclusions. The script must be original analysis, not a substitute for reading the book.

## Acceptance
Script score >= 85, no hard-stop issue, every key factual claim mapped to evidence, narration order matches scene order.
