# Skill: Topic Planning

1. Read the selected book review, historical video projects, and channel positioning.
2. Generate 3–5 genuinely distinct video angles, each framed as a question or explanatory problem.
3. Score each angle using the topic rubric in `docs/QUALITY_GATES.md`.
4. Select an angle only if it has a clear answerable question, a defensible claim, enough evidence, and meaningful differentiation from previous videos.
5. Write `03_topic/topic_brief.md`: target audience, central question, thesis, audience payoff, argument outline, counterargument/limits, source needs, prior-video comparison, title direction.
6. Update `video_projects.csv` and project state.

Avoid “这本书讲了什么” as the only angle. Do not use sensational framing that the evidence cannot support.
