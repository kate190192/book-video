# Video Project Workspace

Copy this template to `projects/<project_id>/`; do not edit the template in place. Keep stage artifacts and update `project_state.json` after each gate.

- 01_book_discovery: candidate list
- 02_book_review: identity, scoring, deduplication
- 03_topic: topic brief
- 04_research: research summary and evidence ledger
- 05_script: script, scene plan and citation map
- 06_editorial: independent review
- 07_production: manifest, logs and rendered media
- 08_video_qa: final QA
- 09_metadata: title, thumbnail brief, description and metadata
- 09_publish: private verification and approval evidence
- 10_analytics: performance review

Never put secrets or tokens in this workspace or commit private audience data.
