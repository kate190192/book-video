# 标准作业程序（SOP）

## 目标

以可重复、可追踪的方式生产高质量 YouTube 读书视频。默认面向中文观众，主题覆盖心理学、认知科学、社会学、人类学、哲学、思想史、经济学、行为经济学、历史、科学与演化、技术和未来社会。频道实际定位以 `config/project.yaml` 为准。

## 阶段 0：书籍发现

每轮建立至少 20 本原始候选作为检索目标，不代表必须入选 20 本。优先从出版社目录、作者/机构主页、学术书评、专业媒体、图书馆目录、重要奖项名单、课程书单和相关论文参考文献发现书籍。覆盖多个学科，但不强求各学科平均分配。

输出：`projects/<id>/01_book_discovery/candidates.md`。每条候选至少记录书名、作者、出版/版本线索、学科、发现来源、潜在核心问题和待核验项。来源不可访问或身份不明的书籍标记为待核验，不得进入优先队列。

## 阶段 1：书籍核验、评选与去重

先确认作品身份、作者、出版社、出版年份/版本及书籍实际内容。优先使用出版社、作者/机构页面、图书馆目录等可靠来源交叉验证。按 `skills/book-selection/SKILL.md` 的评分表评分，并与 `data/books.csv`、历史决策和已发布视频查重。

区分三个判断：
- **作品质量**：是否有知识贡献、可靠论证和长期价值。
- **视频潜力**：是否能形成清晰、具体、有张力的中心问题。
- **制作优先级**：受众适配、时机、素材可获得性、频道内容组合和历史数据。

输出：`02_book_review/book_review.md`，更新 `books.csv` 与 `book_decisions.csv`。未通过硬性准入条件者不得因高分入选。

## 阶段 2：视频选题

不要直接把“介绍一本书”当作选题。围绕一个可回答的问题、一个常见误解、一个机制解释或一组有意义的争议形成角度。先检索已发布内容和在制项目，避免相同书籍、相同结论、相同叙事结构重复出现。

选题评分（100 分）：问题重要性 20、受众相关性 15、观点/机制清晰度 20、证据可支撑性 20、叙事张力 15、与频道差异化 10。建议 75 分以上进入研究，65–74 分修改后复评，低于 65 分淘汰。事实与证据硬伤不可由总分抵消。

输出：`03_topic/topic_brief.md`，包含中心问题、目标观众、观众看完能理解什么、核心主张、反方/限制、与历史视频的差异。

## 阶段 3：研究与证据包

从可靠来源建立证据包。至少覆盖：
- 书籍本身：可合法获取的目录、作者访谈、出版社简介、作者公开演讲或可引用摘录；
- 独立来源：专业书评、学术评论、相关研究、权威机构材料；
- 争议与限制：重要批评、后续证据、适用范围和未解决问题。

区分作者主张、研究共识、争议观点和视频创作者的解释。每条重要事实记录来源名称、URL、作者/机构、发布日期（如可得）、支持的具体主张、可信度和访问日期。不要把书中论点直接描述为科学共识。不得伪造页码或引文。

输出：`04_research/evidence_ledger.md`、`04_research/research_summary.md`。

## 阶段 4：脚本撰写

按配置时长写作。中文旁白可先按约 280–320 字/分钟估算，再以实际配音速度校正；不要为满足字数牺牲论证。

推荐结构：
1. **开头**：用具体困惑、反直觉现象或现实冲突建立问题；避免空泛寒暄和夸张承诺；自然引入书籍及其解释价值。
2. **中段**：围绕中心问题推进 3–5 个逻辑节点。每个节点包含主张、解释、证据/例子、边界或反例；节点间必须存在因果、递进、对比或修正关系，而非简单拼接。
3. **结尾**：明确回答开头的问题，提炼书籍贡献及局限，给观众留下有依据的判断。可简短邀请评论，但不使用模板化喊话。
4. **制作标记**：按 MoneyPrinterTurbo 适配器支持的格式生成场景/段落分段、旁白、画面提示和字幕文本。未确认工具支持前，保存为中立的 `script.md` 和 `scene_plan.json`，由适配器转换。

输出：`05_script/script.md`、`05_script/scene_plan.json`、`05_script/citation_map.md`。

## 阶段 5：独立审稿

审稿 Agent 不得只润色原稿，必须从审稿人视角独立检查：
- 中心问题是否明确，主张是否一致；
- 论证是否成立，因果是否过度推断；
- 是否准确区分书中观点、外部研究与创作者解释；
- 是否有事实错误、伪引文、无来源断言、遗漏重要反方；
- 开头是否建立问题，中段是否逐步回答，结尾是否真正收束；
- 是否存在重复、空话、机械转场、过度口语化或逐章摘要；
- 版权风险和必要披露。

输出：`06_editorial/review_report.md`。总分 85/100 以上且无硬性问题才通过。否则按问题清单修订并重新审稿，最多两轮；仍不通过则阻塞并报告。

## 阶段 6：视频制作

制作前确认：
- 最终脚本已通过审稿；
- 旁白、字幕、场景分段可解析；
- 图片/视频素材路径存在或有明确生成策略；
- 目标分辨率、帧率、宽高比、语言、配音和字幕设置明确；
- MoneyPrinterTurbo 的实际版本、调用方式、模型配置、输入输出路径已通过本地测试。

执行细则见 `skills/video-production/SKILL.md` 与 `docs/INTEGRATIONS.md`。不得臆造 CLI 参数。失败后最多重试两次；每次必须根据错误日志修复不同根因，不能无变化地重复调用。

输出：`07_production/production_manifest.json`、成片文件、制作日志和工具版本记录。

## 阶段 7：成片验收

按 `skills/video-qa/SKILL.md` 检查画面、音频、字幕、事实、版权、时长和完整性。能用脚本检查的项目必须自动检查；语义匹配、发音、画面质量等必须通过抽样播放或人工/视觉模型审查。不能仅以“文件成功导出”判定通过。

输出：`08_video_qa/qa_report.md`。不通过则列出时间戳、问题严重级别、修复方式，回到制作阶段。

## 阶段 8：封面与发布元数据

至少提出 3 个标题候选与 2 个封面方向，评分后选优。标题应准确点题、明确书籍或核心问题，不得使用误导性承诺。封面信息层级清晰、移动端可读、避免无授权人物肖像和盗用书封。

视频描述包括：内容简介、核心议题、书籍书目信息、主要参考来源、版权/AI 使用披露（按平台政策及实际情况）、章节时间戳（仅在准确生成后）、必要的免责声明。标签应相关，不堆砌无关热门词。

输出：`09_metadata/title_options.md`、`thumbnail_brief.md`、`video_description.md`、`metadata.json`。

## 阶段 9：上传、私密验收与发布

上传流程必须遵守 `skills/publish-and-learn/SKILL.md`：
1. 预检凭据、频道、文件、元数据与目标频道；
2. 上传为私密；
3. 保存远端视频 ID 和上传响应；
4. 查询处理状态，确认播放、字幕、封面、描述、可见性；
5. 生成私密验收报告；
6. 等待明确的人类授权；
7. 获授权后才切换为公开/定时公开；
8. 保存发布 URL、时间和操作记录。

没有明确授权记录不得公开。若远端状态不确定，先查询再继续，不得盲目重复上传。

## 阶段 10：发布后复盘

按配置的观察窗口记录曝光、点击率、平均观看时长、留存曲线、流量来源、评论质量和订阅转化（仅记录实际可获得的数据）。区分包装问题、开头问题、内容结构问题、受众匹配问题与平台分发波动，不根据单一指标草率下结论。

输出：`10_analytics/analytics_review.md`，并更新选书/选题策略。不得将未经授权的个人数据写入公共仓库。

## 每周书籍发现循环

建议每周执行一次：收集候选 → 可靠来源核验 → 作品身份与版本归组 → 评分 → 查重 → 更新台账 → 生成优先制作、长期储备、观察和拒绝清单。历史台账不完整时，必须说明去重范围有限，不得声称“已与全部历史去重”。
